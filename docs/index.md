# LibreLibrary

LibreLibrary is a free, open-source, self-hosted personal library server. It catalogs your books, tracks what you read and lend, and offers an API for everything the web interface can do.

The project is in early development, and there is no release yet. The REST API works today, and [getting started](getting-started.md) shows how to run it. The [architecture](design/architecture.md) describes what is planned.
